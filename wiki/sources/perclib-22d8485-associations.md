## Hypotheses within conjunctions

The finite-volume file keeps countability inside the measurable-event clauses. It is not a global hypothesis on finite witnesses, the cluster partition, or the pointwise indicator sum. Its finite component-sum result separately quantifies over a finite ambient vertex type and a finite induced domain of an arbitrary ambient type. These induced clusters differ from full-cluster intersections with a finite observation window. The Q0D1 two-point identities use the source's outer-measure convention without countability; they do not establish measurability of every ambient connection event. The file's witnesses cover an uncountable real vertex type, threshold zero in an empty window, an open two-vertex connection with a finite witness, and an empty finite host.

The symmetry file separates arbitrary-vertex erasure from countable-vertex cluster measurability. Equality of extended-volume laws is used directly for measurable volume events and nonnegative lower integrals, including infinite values. The standard Borel assertion uses existing instances for the coordinate sigma-algebras. The disjoint-block assertion is for fixed blocks and measurable observables on arbitrary index sets; it neither requires finite blocks nor applies merely because adaptively chosen blocks happen to be disjoint. The witnesses compare diagonal parameters zero and one on two vertices, preserve infinite susceptibility in the all-open countable model, include the empty configuration space, and use two infinite integer blocks.
