## Finite profiles and exact refinement

The profile proof repeats the coordinate induction with a coordinate-dependent probability. Positivity of the coefficient 1−2p is needed only to substitute the induction bounds. The weighted-sum splitting and relabelling identities hold for arbitrary real profiles; monotonicity in an observable needs probability-range parameters.

The OR refinement uses a common finite number of copies and a separate copy probability for each original coordinate. Finiteness permits one common number large enough for all coordinates below one. All open copies above a finite original witness provide its lift. Only an inclusion between disjoint-occurrence events is used. The algebraic refinement identity also covers zero copies, but reconstructing a prescribed profile uses a positive number. Profiles with coordinates equal to one are reached by scaling all coordinates slightly toward zero and using continuity of finite event probabilities. Mixed 1,0,3/4 coordinates and an empty type are anonymous witnesses.

## Countability and outer measure

The truncation of an increasing event consists of configurations supported in a finite set which already belong to the ambient event. Its cylinder is a subset of that event. The union of truncated disjoint-occurrence cylinders is exactly finite-certificate disjoint occurrence. It is not claimed that truncations exhaust the original event: the event of infinitely many open coordinates is the source's counterexample.

The deterministic union and directedness identities hold on arbitrary coordinate types, as do the finite-cylinder statements. Countability is used for the countable union of cylinders and its measure limit. Neither original increasing event needs to be measurable; its outer measure bounds every cylinder below it. The resulting disjoint occurrence is measurable. Profiles may contain zero or one or approach one without a uniform gap. Iterated disjoint occurrence uses increasingness at each stage and yields a finite product bound, including the empty-list case. The article's measurable-event assertions are specializations, not replacements.
