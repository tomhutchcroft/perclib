## Scope and implementation boundaries

The cutoff probability theorem is almost sure, simultaneous in the root. Deterministic confinement holds when a configuration itself has no long edges; a zero probability outside the cutoff does not remove exceptional configurations from the ambient space. The ball cardinality theorem is an equality despite its docstring saying "at most". Nonzero modulus is required for finite coefficient groups, while the path-level inequality does not need it. The radial hypotheses in the mass and threshold theorems specify all unordered pairs, including diagonal weight C; loop invariance supplies the article's arbitrary-diagonal formulation. The extended quotient for an omitted row uses truncated subtraction and zero times infinity equal to zero, so it must not be read as a finite real formula when Nr >= 1. The sharp finite-row applications require Nr < 1 and, for the susceptibility estimate, beta M < 1. The M = 0 case is retained. Anonymous examples use L = 2, d = 1, C = 1, r = 1/4 and beta = 1, and the zero-amplitude kernel.

The supercritical module supplies calculus and exhaustion, with the differential inequality for every finite root-containing escape event as an explicit hypothesis in its percolation conclusions. It does not introduce an Input structure, nor prove that hypothesis internally. No transitivity or row summability is needed once it is assumed. The intensity integration works by monotonicity of s f(s) − s; the probability-parameter form uses (1−g(s))s/(1−s). Neither divides by 1−f or 1−g. The endpoint t in the global analytic implication need not carry a function value or continuity. Its witnesses are scalar analytic examples, not a compiled percolation witness of the whole conditional premise. The source therefore supplies part of L0TE, not the complete identification of thresholds.

The tightness proof is on full-cluster intersections. Finite path witnesses can leave the observation window, and the distinguished root may be outside it. Deleting loops and retaining the root's connected component gives a finite connected edge set to which the imported splitting theorem applies. Its endpoint coverage retains the root in a piece; its marked-count guarantee makes each other piece witness the maximum event. The maximum argument uses an attaining root to prove event inclusion, not a union bound over all roots. Finite certificates allow repeated countable-profile BK directly, including endpoint probabilities. The source keeps k >= 1, real lambda >= 1, and the original tail conventions and constants in the imported property definitions. It concludes with the imported numerical implication to universal tightness.
