## Metric and probability scope

The source graph ball uses a strict inequality in extended graph distance. Disconnected vertices have distance infinity and are excluded from every finite-radius ball. The article first proves the closed-ball statement by bounded-length walks and then obtains the source open-ball statement; it explicitly distinguishes their radius-zero values. No totalized finite distance is used for disconnected vertices.

For probabilistic local finiteness the off-diagonal row is finite at each vertex. It need not have a common bound, much less one below one. The source applies first Borel-Cantelli; the article obtains the same finite-neighbour conclusion from the expected-degree identity and intersects over countably many vertices. The deterministic finite-ball induction needs no countability. Local finiteness neither forces finite clusters nor makes a long-range graph's possible coordinate set locally finite.

The global-event exposition distinguishes all-pairs connection from connectedness with a nonempty-vertex requirement. On empty vertices the former is certain and the latter impossible. The all-finite-clusters event imposes no common finite bound; the extended bound infinity in the bounded-cluster event is tautological. Decreasingness of the two size events is a direct expository consequence beyond the listed source measurability statements.

The spanning certificate is a finite set of pair coordinates, not a finite vertex set with an infinite boundary. Its spanning hypothesis forces finite vertices, so its probability bound needs no separate countability hypothesis. Diagonal coordinates can occur in that set but only weaken the product bound. The finite Harris product has an empty-product singleton case. The isolated-vertex upper bound requires a second vertex and would fail on a singleton; its event identity and product formula reuse the open-degree article's canonical isolation assertion.

The source witnesses cover a row equal to one, arbitrary open loops, the empty graph, a spanning path on three vertices, and the two-vertex isolation formula.
