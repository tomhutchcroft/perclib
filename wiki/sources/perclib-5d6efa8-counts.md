## Scope and endpoint conventions

Only the chosen coordinate set is finite; the ambient index type is arbitrary. The first-moment identities use marginals alone. The count law and exponential-moment product use independence of distinct coordinates. Centering a coordinate by its own parameter preserves that independence.

The source gives each one-sided bound for nonnegative deviations even when the chosen set is empty: its real division by zero makes the exponential bound one. The article states the sharper exact empty-count law separately and writes the quotient bound only for a nonempty set. At deviation zero the event has probability one in the empty case. At probabilities zero or one the count is deterministic, and zeroth powers in the binomial formula are one. For a threshold larger than the set size the binomial mass is zero.

The finite assignment sum in CPD6 and the two-sided union bound in XSA6 are additional exposition. The centered exponential-moment proof derives the same one-coordinate sub-Gaussian constant directly; it does not claim to reproduce mathlib's proof. The real-valued and extended nonnegative expectations agree for a bounded finite count. The arbitrary-set cardinality identity does not justify an uncountable interchange with expectation.

The bond specializations count coordinates, including any diagonal pairs present in the chosen set. To count graph neighbours, remove the root before forming incident pairs. An entire boundary can have infinitely many possible pairs even if the vertex window is finite. Neither adaptive coordinate selections nor cluster-membership indicators satisfy the hypotheses merely by having finite cardinality.

Source witnesses include two fair coordinates, deterministic zero/one parameters and a finite set inside an infinite ambient type. These witnesses do not increase the theorem count.
