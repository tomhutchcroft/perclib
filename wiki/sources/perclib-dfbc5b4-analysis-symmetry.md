## Scope and provenance

The convolution source attributes new proofs to PROVER-F and derives the series estimates from mathlib’s finite Hölder inequalities. Its group need not be countable or Abelian; all sums are extended nonnegative sums. Symmetry is required for the return bounds, while normalization to a probability measure is not. The examples include a two-point indicator convolution on the integers and the symmetric nearest-neighbor walk.

The regular-variation interface attributes its original definitions to Bingham–Goldie–Teugels, Sections 1.1–1.4. Tail measurability and eventual positivity differ from the weaker, nonmeasurable eventual-nonvanishing interface in the outside branch. The header attributes three later definitions to yujinhkim/lrp, branch critical-lrp-1, commit d382e4c28d92dd4e698ebf4f2aaf0bc932ae73fc, files PercLib/CriticalLRP/Analysis/RegularVariation.lean and GeneralInverse.lean, under Apache-2.0. It gives upstream commit 3b3d1d0e43ef940bfaa2292ee5c2ee094ac4edbf. This inventory records the merged source’s attribution; it does not claim independent verification of that upstream commit. The accompanying interface lemmas and witnesses are described as new. No outside-branch code was built or executed for this reading. The tag annotation on the representation theorem is source evidence only; the preview’s compiled manifest is unchanged.

The hierarchical source attributes new proofs to PROVER-G, using the library’s geometry and transport results. Its isometry construction is valid for any Abelian coefficient group. Countability appears in the cluster-distribution and internal-event applications, and finite coefficient cardinality in the shell average. A point in the stated shell prevents division by a zero shell cardinality. The witnesses use one-dimensional binary coefficients and a geometric radial kernel.

The long-range source records the outside-branch premise, with new proofs from the private library’s transport lemmas. Its header identifies the same fork commit and upstream commit, the files VolumeTailAllN.lean, VolumeTailUpper.lean and CountableProduct/GhostField.lean, contributor yujinhkim and Apache-2.0; it explicitly says the upstream commit was not independently verified and no code was copied. The result discharges root dominance of ghost-hit probabilities for full and cutoff radial laws by equality. It does not discharge other hypotheses of the outside volume-tail arguments. Positive field and countability remain in the marked-event interpretation. Formal lower-integral identities without measurability hypotheses must not be read as an assertion of measurability for arbitrary observables.
