## Finite changes {#section-finite-changes}

<a id="tag-D106" data-assertion="proposition" data-title="Existence of an infinite component is invariant under finite edge changes"></a>
<p>If two graphs on the same vertex set differ in only finitely many edges, one has an infinite connected component if and only if the other does. The vertex set need not be countable and the graphs need not be locally finite.</p>
<p><em>Proof.</em> Deleting one edge splits its connected component into at most two components. An infinite component cannot be a union of two finite sets, so at least one resulting component is infinite. Adding one edge joins at most two components; if both are finite, their union is finite. Iterate these observations over the finite set of changed edges. Loops have no effect on components.</p>
<p>This is a statement about existence somewhere in the graph. Deleting one edge can disconnect a specified root from the only infinite component.</p>

## The global event {#section-zero-one}

<a id="tag-H0OC" data-assertion="theorem" data-title="Global infinite-cluster existence has probability zero or one"></a>
<p>For independent bond percolation on a nonempty countable vertex set $V$, the event</p>
<div class="math-display">$$\mathcal I=\{\text{there exists an infinite open cluster}\}$$</div>
<p>is measurable and has probability zero or one, for every profile $q$.</p>
<p><em>Proof.</em> For each root $x$ and integer $n\geq1$, the event $\{|K_x|\geq n\}$ has finite open witnesses: choose $n$ connected vertices and finitely many paths joining them to $x$. It is therefore a countable union of finite-coordinate events. Hence</p>
<div class="math-display">$$\mathcal I=\bigcup_{x\in V}\bigcap_{n\geq1}\{|K_x|\geq n\}$$</div>
<p>is measurable. Countability is used both for the finite-witness union and for the union over roots.</p>
<p>Let $F$ be any finite set of edge coordinates. Set all coordinates in $F$ to zero. This measurable operation leaves $\mathcal I$ unchanged by the preceding proposition, so membership in $\mathcal I$ is measurable using only the coordinates outside $F$. Product independence makes $\mathcal I$ independent of every event determined by $F$.</p>
<p>For completeness, this independence already proves the zero-one conclusion. Every measurable event can be approximated in probability by a finite-coordinate event: the class of events with this approximation property is a sigma-algebra containing the cylinder algebra. For each $\varepsilon&gt;0$, choose such an event $B$ with $\mathbb P(\mathcal I\mathbin\triangle B)&lt;\varepsilon$. Then</p>
<div class="math-display">$$\left|\mathbb P(\mathcal I)-\mathbb P(\mathcal I)^2\right|\leq\left|\mathbb P(\mathcal I)-\mathbb P(\mathcal I\cap B)\right|+\mathbb P(\mathcal I)\left|\mathbb P(B)-\mathbb P(\mathcal I)\right|\leq2\varepsilon,$$</div>
<p>where independence gives $\mathbb P(\mathcal I\cap B)=\mathbb P(\mathcal I)\mathbb P(B)$. Let $\varepsilon\downarrow0$.</p>
<p>The tail sigma-algebra here is the intersection of the sigma-algebras generated by coordinates outside finite sets. Finite changes are changes of edge coordinates, not removal of finitely many vertices; at a vertex of infinite degree those are different operations. The proof uses no spatial ergodicity assumption.</p>

## Relating global existence to a root {#section-root}

<a id="tag-0YH8" data-assertion="corollary" data-title="Root and global supercriticality agree under transitivity"></a>
<p>In a countable independent bond model, put $\theta_x=\mathbb P(|K_x|=\infty)$. Then</p>
<div class="math-display">$$\mathbb P(\mathcal I)=1\quad\Longleftrightarrow\quad\theta_x&gt;0\text{ for at least one }x.$$</div>
<p>If the law is invariant under a transitive group action, this is equivalent to $\theta_o&gt;0$ for any specified root $o$. Consequently, for any family of such transitive independent laws, the sets of parameters defined by positive root percolation, positive global percolation and almost-sure global percolation coincide. Their infima agree, with the same convention for an empty set.</p>
<p><em>Proof.</em> A positive root probability makes the global probability positive, hence one. Conversely, if every $\theta_x$ were zero, countable subadditivity would give $\mathbb P(\mathcal I)=0$. Under transitivity, invariance of the law makes all root probabilities equal. Apply these equivalences at each parameter before taking an infimum.</p>
<p>This identifies threshold conventions; it does not determine whether percolation occurs at the threshold. No monotonicity in the parameter is needed for the equality of the three parameter sets. Monotonicity is a separate ingredient when showing that those sets are intervals.</p>

<a id="tag-1J3B" data-assertion="proposition" data-title="A root percolation event need not have probability zero or one"></a>
<p>For every $p\in(0,1)$, there is a countable independent bond model with $\mathbb P(\mathcal I)=1$ and $\mathbb P(|K_o|=\infty)=p$.</p>
<p><em>Proof.</em> Take a ray with vertices $v_1,v_2,\ldots$ and make all its consecutive edges open with probability one. Add a vertex $o$, joined only to $v_1$ by an edge of probability $p$. The ray is an infinite open cluster whether or not this last edge opens. The root belongs to it exactly when that edge opens, an event of probability $p$. This root event changes when one coordinate changes, so it is not a tail event.</p>
<p>The distinction persists in homogeneous percolation on a locally finite transitive graph whenever the model percolates at some $p\in(0,1)$. If the root has degree $D&lt;\infty$, all its incident edges are closed with probability $(1-p)^D&gt;0$, so $0&lt;\theta(p)\leq1-(1-p)^D&lt;1$ even though global existence has probability one.</p>

## Positive paths compare roots {#section-positive-paths}

<a id="tag-C3OO" data-assertion="proposition" data-title="A positive-probability path compares cluster tails at its endpoints"></a>
<p>Suppose $x$ and $y$ are joined by a finite simple path $\gamma$ all of whose edge probabilities are positive, and put $\rho_\gamma=\prod_{e\in\gamma}q_e&gt;0$. Then, for every integer $n\geq1$,</p>
<div class="math-display">$$\mathbb P(|K_x|\geq n)\geq\rho_\gamma\mathbb P(|K_y|\geq n),\qquad \theta_x\geq\rho_\gamma\theta_y.$$</div>
<p>Also $\chi_x\geq\rho_\gamma\chi_y$, allowing infinite susceptibilities. Thus positivity of root percolation and finiteness of susceptibility are each constant on a connected component of the graph of positive-probability edges. This does not assert that the numerical root probabilities or susceptibilities are equal.</p>
<p><em>Proof.</em> Let $E_\gamma$ be the event that all edges of $\gamma$ are open. Distinctness of its edges and independence give $\mathbb P(E_\gamma)=\rho_\gamma$. Both $E_\gamma$ and $\{|K_y|\geq n\}$ are increasing measurable events, so <a href="/tag/X5SS/">Harris association</a> bounds their intersection below by the product of their probabilities. On that intersection, $x$ and $y$ lie in the same cluster, which has size at least $n$. Let $n\to\infty$ to obtain the percolation inequality, and sum the tail inequalities to obtain the susceptibility inequality by Tonelli. Reverse the path to get the equivalences.</p>
<p>No transitivity is used. The comparison constant depends on the path, so finiteness at every root in one support component need not imply a uniform finite bound over its roots. Countability also implies that every probability-zero edge is closed simultaneously almost surely, so random clusters stay inside these deterministic support components.</p>

## Root and global intensity thresholds {#section-intensity-thresholds}

<a id="tag-1C8G" data-assertion="proposition" data-title="The global critical intensity is the infimum of rooted critical intensities"></a>
<p>Let $J_{xy}\geq0$ be finite symmetric intensities on distinct pairs of a nonempty countable vertex set, and let $q_{xy}(\beta)=1-e^{-\beta J_{xy}}$ for finite $\beta\geq0$. Define</p>
<div class="math-display">$$\beta_c(x)=\inf\{\beta\geq0:\mathbb P_\beta(|K_x|=\infty)&gt;0\},\qquad \beta_c^{\mathrm{glob}}=\inf\{\beta\geq0:\mathbb P_\beta(\mathcal I)&gt;0\},$$</div>
<p>as extended nonnegative numbers, with $\inf\varnothing=\infty$. Then</p>
<div class="math-display">$$\beta_c^{\mathrm{glob}}=\inf_{x\in V}\beta_c(x).$$</div>
<p>The rooted threshold is constant on each connected component of the graph $J_{xy}&gt;0$. In particular, if that support graph is connected, every rooted threshold equals the global threshold, without a transitivity assumption.</p>
<p><em>Proof.</em> At every fixed parameter, $\mathcal I$ is the countable union of the root infinite-cluster events. Its probability is positive exactly when at least one of those events has positive probability. Thus the global supercritical parameter set is the union of the rooted parameter sets, and taking its infimum gives the formula, including empty sets. For every $\beta&gt;0$, the edges with $q_{xy}(\beta)&gt;0$ are exactly those with $J_{xy}&gt;0$. The positive-path comparison makes the rooted parameter sets equal within each support component. At $\beta=0$ all off-diagonal bonds are closed, so no additional parameter enters any of these sets.</p>
<p>These are the percolation thresholds used by the finite-intensity interface. No law at parameter $\beta=\infty$ is introduced, no threshold is defined through susceptibility, and the infimum need not belong to its defining set. A connected support identifies rooted thresholds but does not make the percolation probabilities equal.</p>

<a id="tag-AHY3" data-assertion="proposition" data-title="A global intensity threshold need not be attained by any rooted threshold"></a>
<p>There is a countable independent-bond intensity model with $\beta_c^{\mathrm{glob}}=1$, while every vertex has rooted critical intensity strictly greater than one.</p>
<p><em>Proof.</em> Take the disjoint union of rooted binary trees $T_k$, $k\geq1$. Give every tree edge in $T_k$ intensity</p>
<div class="math-display">$$c_k=\frac{\log2}{1+1/k},$$</div>
<p>and give all other pairs intensity zero. At parameter $\beta$, the tree-edge probability is $p_k=1-e^{-\beta c_k}$. The <a href="/tag/CQYY/">binary-tree calculation</a> gives positive root percolation exactly when $p_k&gt;1/2$, or $\beta&gt;1+1/k$. The positive-path comparison gives this same parameter set at every vertex of $T_k$. Hence every root in $T_k$ has threshold $1+1/k$, while</p>
<div class="math-display">$$\beta_c^{\mathrm{glob}}=\inf_{k\geq1}(1+1/k)=1.$$</div>
<p>At $\beta=1$ no component percolates, and countability rules out an infinite cluster anywhere. At every $\beta&gt;1$ some component is supercritical, so global existence has probability one. All intensities are finite and the vertex degrees are at most three; this example does not rely on an infinite-degree vertex or a probability-one edge.</p>

## Susceptibility can diverge without percolation {#section-susceptibility-threshold}

<a id="tag-SA9P" data-assertion="proposition" data-title="A bounded-degree intensity model separates susceptibility divergence from percolation"></a>
<p>There is a connected countable host graph of maximum degree three, with finite nonnegative edge intensities, for which every cluster is finite almost surely at every finite parameter $\beta\geq0$, but</p>
<div class="math-display">$$\mathbb E_\beta|K_o|&lt;\infty\quad\Longleftrightarrow\quad\beta&lt;\log2.$$</div>
<p>Thus all rooted and global percolation thresholds are infinite, whereas the infimum of parameters with infinite root susceptibility is $\log2$.</p>
<p><em>Proof.</em> Start with a backbone ray $b_0,b_1,\ldots$, rooted at $o=b_0$, and give its edges intensity one. For each $k\geq1$, attach to $b_k$ a path containing $2^k$ new vertices. Give each of the $2^k$ edges from $b_k$ along this path intensity $k^2$. All other pairs have intensity zero. Every intensity is finite, although there is no uniform upper bound. The graph has maximum degree three.</p>
<p>Fix a finite $\beta$ and write $p=1-e^{-\beta}&lt;1$. The backbone has no infinite open interval almost surely: the probability that the next $n$ edges after any given vertex are all open is $p^n\to0$, and there are countably many possible starting vertices. Every open backbone component is therefore finite. Each decoration is finite and attaches at only one vertex, so it cannot bypass a closed backbone edge. Consequently every full cluster is finite almost surely.</p>
<p>There is a unique path from $o$ to every vertex. Put $q_k=1-e^{-\beta k^2}$. Summing the connection probabilities gives the exact extended identity</p>
<div class="math-display">$$\chi_o(\beta)=\sum_{k\geq0}p^k+\sum_{k\geq1}p^k\sum_{j=1}^{2^k}q_k^j.$$</div>
<p>If $p&lt;1/2$, bound the inner sum by $2^k$. Both geometric sums converge, giving</p>
<div class="math-display">$$\chi_o(\beta)\leq\frac1{1-p}+\frac{2p}{1-2p}&lt;\infty.$$</div>
<p>If $p\geq1/2$, then $\beta&gt;0$ and Bernoulli's inequality gives $q_k^{2^k}\geq1-2^ke^{-\beta k^2}\to1$. The contribution from the $k$th decoration is at least $(2p)^kq_k^{2^k}$, which is eventually at least $1/2$. Its sum diverges. Since $p\geq1/2$ is equivalent to $\beta\geq\log2$, this proves the claim, including the endpoint. At $\beta=0$ the root cluster is a singleton.</p>
<p>The positive-path comparison shows that every root has the same susceptibility-finiteness range. This is an inhomogeneous model with unbounded edge intensities, not a counterexample to a transitive sharpness theorem. It explains why the library's percolation-threshold definition cannot be replaced by a susceptibility threshold without additional hypotheses and a proof.</p>

## Source scope {#section-source}

<p>This proves the zero-one law and the threshold conventions. It does not prove nontriviality of the threshold, uniqueness of an infinite cluster, or absence of percolation at criticality. The finite-change argument is deterministic; countability and independence enter only in the probabilistic steps.</p>

<p>The support-component comparison, global-infimum identity and non-attainment example are expository extensions of the finite-intensity definitions on pinned main. Their presence here is not a claim that those extensions have compiled proofs or matching source tags.</p>

## Approximation by finite observations {#section-cylinder-approximation}

<p>The product arguments above do not require the coordinate set itself to be countable. In the remaining sections let $I$ be arbitrary, let $\Omega=\{0,1\}^I$ carry its product sigma-algebra, and identify a configuration with its open coordinates. A finite-coordinate event has the form $\{\omega:\omega\cap F\in S\}$, where $F\subseteq I$ is finite and $S\subseteq\{0,1\}^F$.</p>

<a id="tag-DK14" data-assertion="proposition" data-title="Finite-coordinate events approximate every measurable event in finite measure"></a>
<p>For every finite measure $\mu$ on $\Omega$, every measurable $A$ and every $\varepsilon>0$, there is a finite-coordinate event $C$ such that</p>
<div class="math-display">$$\mu(A\mathbin\triangle C)<\varepsilon.$$</div>
<p><em>Proof.</em> Finite-coordinate events form an algebra generating the product sigma-algebra. Let $\mathcal D$ be the class of measurable events with the asserted approximation property. It contains this algebra and is closed under complements. It is closed under finite unions, since the symmetric difference of two unions is contained in the union of the corresponding symmetric differences. If $A_n\in\mathcal D$ and $A=\bigcup_n A_n$, finiteness of $\mu$ gives</p>
<div class="math-display">$$\mu\left(A\setminus\bigcup_{n\leq N}A_n\right)\longrightarrow0.$$</div>
<p>Approximate a sufficiently large finite union by one finite-coordinate event. The triangle inequality for symmetric differences then approximates $A$. Thus $\mathcal D$ is a sigma-algebra and contains every measurable event.</p>
<p>Independence is not used here. Nor is a fixed exhaustion of $I$ required: the finite observation can depend on $A$ and $\varepsilon$. Under a product law, events determined by disjoint coordinate sets are independent; the approximation lemma is what extends calculations on finite observations to arbitrary measurable events.</p>

## Finite modifications on a product space {#section-product-tail}

<a id="tag-D1CH" data-assertion="theorem" data-title="Finite-modification invariance gives the zero-one law on arbitrary coordinate sets"></a>
<p>Let $\mathbb P_q$ be the Bernoulli product law with arbitrary profile $q:I\to[0,1]$. Suppose $A$ is measurable and</p>
<div class="math-display">$$\omega\cup\{i\}\in A\quad\Longleftrightarrow\quad\omega\in A\qquad\text{for every }\omega\in\Omega\text{ and }i\in I.$$</div>
<p>Then $A$ is unchanged by every finite modification, belongs to the sigma-algebra generated by the coordinates outside $F$ for every finite $F\subseteq I$, and $\mathbb P_q(A)\in\{0,1\}$.</p>
<p><em>Proof.</em> Apply the insertion equivalence to $\omega\setminus\{i\}$. If $i\in\omega$, reinserting it recovers $\omega$; otherwise deletion did nothing. Thus deletion also preserves membership, and iteration handles any finite modification.</p>
<p>For a finite $F$, the erasure map $E_F(\omega)=\omega\setminus F$ is measurable using only the coordinates outside $F$: each output coordinate is either an unchanged outside bit or the constant zero. Since $A=E_F^{-1}A$, the event belongs to that outside-coordinate sigma-algebra. Product independence makes it independent of every event determined by $F$.</p>
<p>Choose a finite-coordinate $C$ with $\mathbb P_q(A\mathbin\triangle C)<\varepsilon$, and put $a=\mathbb P_q(A)$. The independence just proved yields $\mathbb P_q(A\cap C)=a\mathbb P_q(C)$, so</p>
<div class="math-display">$$|a-a^2|\leq|\mathbb P_q(A\cap A)-\mathbb P_q(A\cap C)|+a|\mathbb P_q(C)-a|<2\varepsilon.$$</div>
<p>Letting $\varepsilon\downarrow0$ gives $a=a^2$.</p>
<p>The invariance hypothesis is an equivalence, not merely stability under opening an edge. An increasing event need not be a tail event. Parameters zero and one are allowed. On a finite coordinate set, the invariance forces $A$ to be empty or the whole space, since every configuration differs from the empty configuration in finitely many places.</p>
<p>This generalizes the product-space step in <a href="/tag/H0OC/">the global infinite-cluster proof</a>. It does not remove that proof's countability requirement for measurability of the graph event. A deterministic finite-change argument alone does not make an uncountable union of root events measurable.</p>

## Mixing under coordinate relabellings {#section-product-mixing}

<p>Let $e_n:I\to I$ be bijections and write $R_n(\omega)=e_n[\omega]$. The inverse image under $R_n$ of an event on coordinates $G$ depends on $e_n^{-1}(G)$.</p>

<a id="tag-MJD2" data-assertion="theorem" data-title="Law-preserving relabellings that separate finite sets are mixing"></a>
<p>Suppose every $R_n$ preserves $\mathbb P_q$ and, for every two finite sets $F,G\subseteq I$,</p>
<div class="math-display">$$e_n(F)\cap G=\varnothing\qquad\text{for all sufficiently large }n.$$</div>
<p>Then for all measurable events $A,B$,</p>
<div class="math-display">$$\mathbb P_q(A\cap R_n^{-1}B)\longrightarrow\mathbb P_q(A)\mathbb P_q(B).$$</div>
<p><em>Proof.</em> Choose events $C,D$ determined by finite sets $F,G$, with $\delta_A=\mathbb P_q(A\mathbin\triangle C)$ and $\delta_B=\mathbb P_q(B\mathbin\triangle D)$ arbitrarily small. For sufficiently large $n$, the sets $F$ and $e_n^{-1}(G)$ are disjoint. Independence of their coordinates gives</p>
<div class="math-display">$$\mathbb P_q(C\cap R_n^{-1}D)=\mathbb P_q(C)\mathbb P_q(R_n^{-1}D)=\mathbb P_q(C)\mathbb P_q(D).$$</div>
<p>The second equality uses preservation of the law. Moreover,</p>
<div class="math-display">$$(A\cap R_n^{-1}B)\mathbin\triangle(C\cap R_n^{-1}D)\subseteq(A\mathbin\triangle C)\cup R_n^{-1}(B\mathbin\triangle D).$$</div>
<p>Its probability is at most $\delta_A+\delta_B$. Since all probabilities lie in $[0,1]$, the difference between $\mathbb P_q(C)\mathbb P_q(D)$ and $\mathbb P_q(A)\mathbb P_q(B)$ is at most the same quantity. Hence, eventually,</p>
<div class="math-display">$$\left|\mathbb P_q(A\cap R_n^{-1}B)-\mathbb P_q(A)\mathbb P_q(B)\right|\leq2(\delta_A+\delta_B).$$</div>
<p>Finite-coordinate approximation makes the right side arbitrarily small.</p>
<p>The two hypotheses have useful coordinate criteria. Profile preservation $q(e_n(i))=q(i)$ implies preservation of the law by <a href="/tag/VEUZ/">the relabelling identity</a>. Separation holds if, for every fixed $i,j$, the set $\{n:e_n(i)=j\}$ is finite: the exceptional indices for $F,G$ form a finite union of these sets. Neither criterion requires a group action or homogeneity of the profile.</p>
<p>Separation is used only for the two finite approximations, after they have been chosen. Their required separation time need not be uniform over all finite sets. Independence alone supplies the cylinder factorization with $\mathbb P_q(R_n^{-1}D)$; preservation of the law is what replaces this by $\mathbb P_q(D)$.</p>

## Invariant events and observables {#section-product-ergodicity}

<a id="tag-DRQ2" data-assertion="corollary" data-title="Mixing forces invariant events and extended-integer observables to be deterministic"></a>
<p>Under the hypotheses of the mixing theorem, a measurable event satisfying $R_n^{-1}A=A$ for every $n$ has probability zero or one. If a measurable $X:\Omega\to\mathbb N\cup\{\infty\}$ satisfies $X(R_n\omega)=X(\omega)$ for every $n,\omega$, then there is a $c\in\mathbb N\cup\{\infty\}$ such that</p>
<div class="math-display">$$\mathbb P_q(X=c)=1.$$</div>
<p><em>Proof.</em> Apply mixing with $B=A$. The left side is constantly $\mathbb P_q(A)$, so $\mathbb P_q(A)=\mathbb P_q(A)^2$, which forces zero or one. For the observable, every level event $\{X=c\}$ is measurable and invariant, hence has probability zero or one. They form a countable partition of the whole space, so they cannot all have probability zero. At least one has probability one.</p>
<p>No boundedness or integrability of $X$ is required; its almost-sure value may be infinity. The countable level-set argument includes that value as one of the levels. The invariance here is spatial, and does not assert invariance under changes of finitely many bits.</p>

## Translations of an infinite group {#section-group-ergodicity}

<a id="tag-WUAF" data-assertion="theorem" data-title="Translation-invariant bond laws on infinite groups are ergodic"></a>
<p>Let $G$ be any infinite group, written additively and not necessarily commutatively. Suppose its unordered-pair profile satisfies</p>
<div class="math-display">$$q(\{x+g,y+g\})=q(\{x,y\})\qquad(x,y,g\in G),$$</div>
<p>including diagonal pairs. Write $T_g$ for the induced right translation of configurations. Every measurable event invariant under all $T_g$ has probability zero or one, and every measurable translation-invariant observable with values in $\mathbb N\cup\{\infty\}$ is almost surely constant. In fact, along every sequence of distinct elements $g_n\in G$,</p>
<div class="math-display">$$\mathbb P_q(A\cap T_{g_n}^{-1}B)\longrightarrow\mathbb P_q(A)\mathbb P_q(B)$$</div>
<p>for all measurable $A,B$. Countability of $G$ is not assumed.</p>
<p><em>Proof.</em> Right translation of pairs is a bijection, with inverse given by translation by $-g$. Its induced configuration map is measurable, since each output bit reads one input bit. The profile hypothesis and the relabelling identity therefore make $T_g$ measure preserving.</p>
<p>Fix pairs $\{x,y\}$ and $\{u,v\}$. If translation by $g$ sends the first pair to the second, then $x+g$ equals either $u$ or $v$, so</p>
<div class="math-display">$$g\in\{-x+u,-x+v\}.$$</div>
<p>A sequence of distinct $g_n$ therefore gives only finitely many collisions between any fixed two pairs. The separation criterion and the mixing theorem apply. Since an infinite group contains a countably infinite set of distinct elements, choosing one such sequence also proves the event and observable conclusions. Nothing in the argument requires commuting group elements.</p>
<p>For a graph event or observable that is unchanged by deleting loops, it is enough that the profile be translation invariant off the diagonal. <a href="/tag/LNKT/">Erasing the diagonal</a> preserves its law and replaces the diagonal profile by zero, making the modified profile invariant on all pairs. Measurability of the event or observable is still required; the theorem does not provide it for an arbitrary uncountable graph.</p>
<p>In particular, on $\mathbb Z^d$, $d\geq1$, one may take $g_n=nv$ for any fixed $v\ne0$. This covers nearest-neighbour and translation-invariant long-range laws, without a degree bound or a summable row. It also applies to infinite torsion groups: distinct translations suffice, even when no single element has infinite order.</p>
<p>The <a href="/tag/6GNC/">cluster-number argument</a> already proves measurability and translation invariance of the number of infinite components, and proves its almost-sure constancy by this approximation argument. The general theorem here isolates that ergodic step. It neither excludes finite constants larger than one nor proves uniqueness; those conclusions require the additional arguments stated there. In particular, the number of infinite components can change when one bond opens, even though existence of some infinite component is unchanged by finite modifications.</p>
<p>On the integer group, the event that some unordered-pair coordinate is open is measurable as the countable union of the coordinate-open events and is invariant under translations. This is the source's concrete event witness; it concerns raw coordinates, including loops, rather than the existence of a non-loop edge or an infinite cluster.</p>
<p>The <a href="/coverage/sources/perclib-5d6efa8-ergodicity/">three-module source inventory</a> records the arbitrary-coordinate statements, the finite-measure approximation, the separation and law-preservation criteria, and the infinite-group application. It supplies source locators, not compiled tag associations or independent correspondence reviews.</p>


## The line-and-root realization {#section-line-root-model}

<p>The source realization of <a href="/tag/1J3B/">1J3B</a> uses a copy of $\mathbb Z$ and one extra vertex $o$. Give every nearest-neighbour line bond probability one, the bond from $o$ to zero probability $p\in[0,1]$, and all other bonds from $o$ to the line probability zero. Other bonds within the line and all diagonal probabilities are unrestricted.</p>
<p>Countability gives one probability-one event on which all nearest-neighbour line bonds are open and all probability-zero bonds from $o$ are closed. The line is connected and infinite on that event. If the distinguished bond opens, $o$ joins it; if that bond is closed, $o$ is isolated. Hence</p>
<div class="math-display">$$\mathbb P(\mathcal I)=1,\qquad \mathbb P(|K_o|=\infty)=p.$$</div>
<p>Additional line bonds cannot affect either conclusion. The endpoints give an isolated root at $p=0$ and an almost surely percolating root at $p=1$; only interior $p$ is needed to disprove a root zero-one law. Unlike a finite positive-intensity kernel, this construction uses probability-one bonds, so it is a profile example rather than a finite-intensity realization.</p>
<p>At the opposite extreme, on a finite vertex set every cluster is finite for every configuration. The global infinite-cluster event is empty, and so are all rooted percolation parameter sets. This gives both infinite thresholds in <a href="/tag/KB1L/">KB1L</a>, for every finite nonnegative intensity kernel. The global conclusion includes the empty vertex set; a rooted statement requires a chosen vertex. A large-component transition in a sequence of finite graphs is a different notion. The <a href="/coverage/sources/perclib-caed44f-models/">eight-contract inventory</a> includes these finite-host statements and the prescribed-root example.</p>

## The decorated ray inside its host {#section-decorated-host}

<p>The source for <a href="/tag/SA9P/">SA9P</a> embeds the decorated ray in $\mathbb N\times\mathbb N$. Its connected host consists of the backbone edges $(k,0)(k+1,0)$ and every vertical edge $(k,j)(k,j+1)$. This host has degree at most three. Only the backbone and the first $2^k$ vertical edges at $k\geq1$ receive positive intensity. Consequently</p>
<div class="math-display">$$V_* = \{(k,0):k\geq0\}\cup\{(k,j):k\geq1,\ 1\leq j\leq2^k\}$$</div>
<p>is the positive-intensity component containing the root. It is exactly the graph used in the earlier proof. Vertices outside $V_*$ are isolated under the percolation law, although they belong to the connected host. Their susceptibilities are one at every finite intensity. Thus the positive-path comparison transfers the root susceptibility range to every vertex of $V_*$, not to those extra isolated vertices. Every vertex in the enlarged model still has infinite percolation threshold.</p>
<p>For $k\geq1$ and $0\leq j\leq2^k$, the unique route from the root uses $k$ backbone edges and $j$ pendant edges, giving $\tau_\beta(o,(k,j))=p^kq_k^j$. The formula includes the backbone when $j=0$. Connections to vertices outside $V_*$ have probability zero. The source first proves the finite product along this route under a support hypothesis; the particular edge intensities are used only when evaluating that product.</p>
<p>The divergence at the endpoint can be quantified without an asymptotic estimate. If $\beta\geq\log2$ and $k\geq2$, then</p>
<div class="math-display">$$2^ke^{-\beta k^2}\leq2^{k-k^2}\leq\frac14,
\qquad q_k^{2^k}\geq1-2^ke^{-\beta k^2}\geq\frac34.$$</div>
<p>Since $2p\geq1$, the $k$th decoration contributes at least $(2p)^kq_k^{2^k}\geq3/4$ to the susceptibility. Summing over $k$ proves divergence, including $\beta=\log2$. Below that value, the earlier geometric upper bound proves finiteness. At zero intensity every cluster is a singleton.</p>
<p>Almost-sure finiteness needs much less than the specific pendant weights $k^2$. Unit backbone intensities and support on these finite decorations suffice. For a fixed starting index, the event that every subsequent backbone edge opens has probability at most $p^n$ for every $n$, hence zero. Excluding all such events leaves a closed backbone edge beyond each vertex. The part of $V_*$ before that edge is finite, and no pendant can cross it. This proves simultaneous finiteness of all clusters. The <a href="/coverage/sources/perclib-79c3d0e-decorated-ray/">thirteen-contract inventory</a> separates this support argument from the special weights needed for the susceptibility threshold.</p>

## The two-point comparison behind the path bound {#section-path-source}

<p>The source first proves a stronger form of the comparison used in <a href="/tag/C3OO/">C3OO</a>. With $T(y,x)=\mathbb P(y\leftrightarrow x)$, Harris applied to connection and the volume-tail event gives</p>
<div class="math-display">$$T(y,x)\,\mathbb P(|K_y|\geq n)\leq\mathbb P(|K_x|\geq n).$$</div>
<p>This source statement allows $n\in\mathbb N\cup\{\infty\}$; at infinity the event is that the cluster is infinite. Summing the positive-integer tails gives $T(y,x)\chi_y\leq\chi_x$ in extended nonnegative values.</p>
<p>For a finite walk $\gamma$ from $x$ to $y$, let $F$ be its set of distinct unordered bonds. Requiring all bonds of $F$ open has probability $\rho=\prod_{e\in F}q_e$ and forces the connection. Hence $\rho\leq T(y,x)$ and the preceding bounds imply the path inequalities. A walk may repeat an edge: it is counted once in this product. The empty walk has product one. The inequalities also hold when $\rho=0$; positivity is needed only to transfer positivity of percolation or finiteness of susceptibility between roots.</p>
<p>The <a href="/coverage/sources/perclib-22d8485-geometry/">nine-contract inventory</a> separates this arbitrary-walk form from the simple positive path in C3OO. Countability supplies measurability for Harris and the tail sum. The deterministic path lower bound itself needs no countability. Support connectivity gives a positive comparison factor in both directions, but neither equality of the root values nor a uniform bound over an infinite component.</p>


## Components in the unattained-threshold example {#section-unattained-source}

<p>The <a href="/coverage/sources/perclib-3978a2f-normalization/">source for AHY3</a> constructs the kernel on $\mathbb N\times\{0,1\}^{&lt;\infty}$, with component index $n$ corresponding to $k=n+1$ above. It proves the percolation criterion at every vertex, the rooted and global thresholds, and the probability-zero and probability-one conclusions at and above the global threshold. It also gives the uniform bounds $J_e\leq\log2$ and degree at most three.</p>
<p>There are two separate steps in restricting to one component. Its embedding gives one comparison of percolation probabilities; for the reverse comparison, almost surely no edge outside the disjoint-tree host is open. Countability makes that simultaneous statement valid. The ambient configuration space still contains exceptional edges between components, so deterministic confinement is used only after this probability-one restriction. Finally, global existence above one follows from positive probability and the independent-bond zero-one law; it does not assert probability-one percolation at every fixed root.</p>
